Help

Import Save replaces the baseline for editable builds. Builds stores loadouts and Mid-Run Changes. Setup assigns builds to run slots. Started runs keep their own frozen build.

Play is modeled elapsed time. Time is real elapsed simulation time. Hour is a run average; Min is the current or final rolling rate. Module Shards assume all module drops are shattered. Dice includes Fetch.

Sampled groups events for speed. Detailed processes more events. Reference uses slow frame validation. Sim Seed repeats this simulator’s RNG; it is not a game seed.

Predictions are approximate. Calibration includes selected T21 and T22 farming reports. Tournament comparison is in progress.
